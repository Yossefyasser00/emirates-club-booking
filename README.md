# ⚽ Emirates cLub — مجمع ملاعب كرة القدم المتطور

## 🚀 تشغيل النظام

### بنقرة واحدة (Double Click):
- افتح ملف **`start.bat`** وسيقوم بتشغيل السيرفرات وفتح الموقع مباشرة.

---

## 🔐 فصل العملاء عن الإدارة تماماً

1. **واجهة العميل (Customer):**
   - الرابط: **`http://localhost:5173/`**
   - حجز سريع وسلس بدون تسجيل حساب نهائياً.
   - لا توجد أي أزرار أو روابط تشير للوحة الإدارة.

2. **بوابة الإدارة المحمية (Admin Portal):**
   - الرابط السري: **`http://localhost:5173/management`**
   - محمية بنظام **JWT Token Authentication + Bcrypt Encryption** على مستوى الـ Backend والـ Frontend.
   - كلمة المرور الافتراضية للوحة التحكم: **`Emirates2026!`**

---

## 🎨 مميزات التصميم والـ UI/UX
- **الهيرو (Hero):** تصميم CSS تفاعلي بنمط ملعب كروي ليلي مع أضواء كاشفة وخطوط نجيل ثلاثية الأبعاد بدلاً من الصور الثابتة.
- **الشعار (Logo):** شعار Emirates Club مدمج في الـ Navbar والـ Footer وصفحة الدخول.
- **لوحة التحكم:** إحصائيات حية، إدارة الملاعب، حظر المواعيد، تأكيد إيصالات الدفع، وإدارة الكوبونات.
